# Avícola del Ebro

Proyecto de desarrollo de una aplicación de gestión empresarial para **Avícola del Ebro**, una empresa ficticia dedicada a la cría de pollos y gallinas, la producción de huevos y la comercialización de carne de pollo.

## Objetivo

Desarrollar una aplicación utilizando Odoo y Python para gestionar diferentes áreas de la empresa, como las naves avícolas, los lotes de aves, la producción, los productos y los proveedores.

## Tecnologías

* Python
* Odoo
* XML
* PostgreSQL
